# Estándares de Codificación Java

- **Inmutabilidad**: Uso de DTOs y clases de dominio con constructores seguros.
- **Inyección de Dependencias**: Exclusivamente por constructor con `private final`.
- **Nomenclatura**: CamelCase descriptivo en español/inglés técnico consistente.
- **Documentación de Métodos**: Javadoc conciso en interfaces de servicio público.
