# Inventario de Dependencias Maven

- `spring-boot-starter-web`: Creación de controladores REST y servidor embebido Tomcat.
- `spring-boot-starter-data-jpa`: Abstracción ORM con Hibernate y repositorios JPA.
- `postgresql`: Driver JDBC para comunicación nativa con PostgreSQL.
- `spring-boot-starter-validation`: Soporte de validaciones declarativas JSR-380.
- `lombok`: Reducción de código repetitivo (getters, setters, constructores).
