# Cálculo de Percentiles de Espera Clínica

El servicio calcula:
- **P50 (Mediana)**: Tiempo promedio de espera real para la mayoría de pacientes.
- **P90**: Umbral de tiempo donde el 90% de los pacientes ya fueron llamados a consulta.
- Permite detectar cuellos de botella en turnos específicos del servicio de urgencias.
