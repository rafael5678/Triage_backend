# Guía de Contribución al Backend

Instrucciones para colaboradores del proyecto:

1. Utilice ramas con convención semántica: `feat/`, `fix/`, `docs/`, `refactor/`.
2. Asegure que `./mvnw test` o `mvn clean test` pase satisfactoriamente.
3. Mantenga las migraciones SQL coordinadas con los cambios de entidad JPA.
